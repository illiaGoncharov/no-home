# Документация проекта NOHOME

## Обзор документации

Данная папка содержит техническую документацию для разработчиков, работающих с проектом NOHOME.CLOUD.

## Структура документации

### [architecture.md](./architecture.md)
Подробное описание архитектуры системы, включающее:
- Обзор файловой структуры
- Описание основных компонентов
- Система управления текстом (Remote Control)
- Навигационная система
- Система предметов (Items System)
- Технические особенности и ограничения

### [technical-guide.md](./technical-guide.md)
Практическое руководство для разработчиков:
- Технологический стек
- Архитектурные паттерны
- Инструкции по модификации кода
- Отладка и диагностика
- Стандарты кодирования
- Оптимизация производительности

### [quick-reference.md](./quick-reference.md)
Краткая справочная информация:
- Основные файлы для модификации
- Частые операции
- Команды деплоя
- Решение типичных проблем
- Полезные команды

## Для новых разработчиков

Рекомендуемый порядок изучения документации:

1. **Начните с [quick-reference.md](./quick-reference.md)** - получите общее представление о структуре проекта
2. **Изучите [architecture.md](./architecture.md)** - поймите архитектуру и основные компоненты
3. **Используйте [technical-guide.md](./technical-guide.md)** - для практической работы с кодом

## Обновление документации

Документация должна обновляться при внесении значительных изменений в архитектуру или добавлении новой функциональности.
