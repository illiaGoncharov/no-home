# NOHOME.CLOUD - Архитектура системы

## Обзор проекта

NOHOME представляет собой интерактивный веб-проект, построенный на платформе WordPress с кастомной темой. Проект реализует концепцию виртуального дома с интерактивными комнатами, сложной навигационной системой и множественными пользовательскими интерфейсами.

## Центральная система управления (Remote Control)

### Архитектура пульта управления

Система пульта управления является центральным элементом пользовательского интерфейса, реализованная в файле `horse-text-handler.js`. Система поддерживает два основных режима работы:

1. **Текстовый режим** - отображение контекстных подсказок при взаимодействии с элементами
2. **Режим плеера** - отображение информации о воспроизводимом аудиоконтенте

### Система hover-текстов

Каждый интерактивный элемент на сайте имеет связанный с ним текст, который отображается в пульте при наведении курсора:

**Главная страница:**
- Стикеры: "sorry for being weird it's my first time being alive"
- Стикер с заметкой (note8): "you can leave a note or leave nothing"

**Навигация по комнатам:**
- Кнопка скелета: "please, select one of my limbs"

**Спальня:**
- Рюкзак/чемодан: "watch out! Is something or someone behind you? are objects also subjects?"
- Силуэт в окне: "have you ever been activated? please, check in with your soul"
- Вид из окна: "do you know the temperature of air outside someone's window?"

**Пещера:**
- Защитный шлем: "mind your head"
- Колонка: "do you know how to follow well? are you a considerate person?"
- Рация: "do you know how to listen carefully?"
- Зеркало: "sorry, your reflection is not renderable"

**Столовая:**
- Стол: "I hope this table is adaptive enough for you"
- Ноутбук: "my heart is surrounded by bones. I am able to hear both the heart and the bones. What about you?"
- Камера: "the motives of this camera are not clear, the date and time are broken"
- Жесткий диск: "don't rush to leave, it's a fine day"
- Рукописный текст: "please, do not leave. I will hide away shortly and you can scroll."

**Золотая комната:**
- Дверь: "what do you prefer - closed/open doors or closed/open locks?"
- Замок: "do you know how to cipher?"
- Крысы: "oh no, i am sorry, the mice have escaped the lab!"

**Главная страница (классики):**
- Числа на дорожке: "the numbers on your way are a chance to establish contact with them"

## Навигационная система

### Skeleton Navigation

Система навигации между комнатами реализована через интерактивную SVG-карту скелета:

- Центральная кнопка `.skeleton-button` активирует навигационное меню
- SVG-области соответствуют различным комнатам дома
- AJAX-переходы обеспечивают навигацию без перезагрузки страницы
- После каждого перехода вызывается реинициализация системы hover-текстов

### URL-структура

```

/0selectedarea1      # Спальня
/0selectedarea2      # Пещера  
/0selectedarea3      # Столовая
/0selectedarea4      # Чердак
/0selectedarea5      # Золотая комната
```

## Система предметов (Items System)

### Архитектура модуля

Система предметов реализована в файле `items.js` и включает следующие компоненты:

1. **Рюкзак** - анимированные плавающие предметы
2. **Чемодан** - сетка предметов с возможностью загрузки файлов
3. **iPhone** - симуляция мобильного интерфейса с экраном блокировки
4. **Документы** - система пролистывания страниц дневника
5. **Камера** - галерея из 100 фотографий с навигацией
6. **MP3 плеер** - винтажный интерфейс с двумя сторонами по 5 треков

### CAPTCHA система

Система CAPTCHA активируется для определенных интерактивных элементов:
- iPhone в столовой (требует прохождение CAPTCHA)
- Колонка в пещере (требует прохождение CAPTCHA)
- Рюкзак и чемодан (прямой доступ без CAPTCHA)

## Навигационные инструменты

### Панель инструментов

Нижняя панель содержит следующие инструменты:

1. **Контроль громкости** - визуальный слайдер с красным индикатором
2. **Переводчик** - поддержка 50+ языков через Google Translate
3. **X-Ray режим** - инверсия цветов всего интерфейса
4. **Система предметов** - доступ к Items System

## Технические особенности

### JavaScript архитектура

- Модульная структура с изолированными пространствами имен
- Event-driven архитектура для взаимодействия между модулями
- Глобальные функции через объект `window` для межмодульной коммуникации
- Система реинициализации для AJAX-переходов

### CSS методология

- Viewport units (vh, vw) для адаптивного дизайна
- CSS Grid и Flexbox для компоновки
- Кастомные анимации через @keyframes
- Система z-index для управления слоями

### Цветовая схема

```css

Интерактивные элементы: white, rgba(255,255,255,0.x)
```

## Процесс разработки и деплоя

### Локальная разработка

Проект использует Docker для локальной разработки:
- WordPress доступен по адресу http://localhost:8000
- phpMyAdmin доступен по адресу http://localhost:8003
- MySQL база данных в контейнере

### Деплой на продакшн

Автоматизированный деплой через FTP:
- Скрипт `deploy.sh` для различных типов деплоя
- Поддержка hotfix деплоя только JavaScript файлов
- Раздельный деплой кода и изображений

### Контроль версий

- Git репозиторий с историей изменений
- Коммиты перед каждым деплоем
- GitHub как удаленный репозиторий

## Известные технические ограничения

### Проблемы производительности

1. **Конфликт анимаций** - CSS и JavaScript анимации могут конфликтовать
2. **Кеширование** - браузерный и серверный кеш может препятствовать обновлениям
3. **404 ошибки** - периодические проблемы с загрузкой JavaScript модулей

### Решения

1. Использование только JavaScript анимации в системе пульта
2. Принудительная очистка кеша при критических обновлениях
3. Резервная загрузка через FileZilla при проблемах с автоматическим деплоем

## Масштабируемость

### Добавление новых комнат

1. Создание нового файла `[local]newroom.php`
2. Добавление SVG области в главную страницу
3. Регистрация hover-обработчиков в `horse-text-handler.js`
4. Обновление навигационной системы

### Расширение функциональности

Архитектура поддерживает добавление новых модулей через:
- Создание новых JavaScript файлов
- Регистрацию в системе Items
- Интеграцию с центральной системой управления текстом
